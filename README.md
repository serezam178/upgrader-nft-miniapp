# UpgraderNFT Mini App — визуальный образец

Статический каталог для Telegram Mini App. Оплата, заказы, аренда и выдача товаров **не подключены**. Цены и доступность не обновляются; карточки не являются предложением купить товар. Кнопка карточки открывает диалог и ведёт в чат бота, где оформление также пока недоступно.

Первые 12 анимированных превью Durov’s Glasses взяты из публичных `.tgs`-ресурсов `nft.fragment.com` и преобразованы в локальные Lottie JSON. Это образцы внешнего каталога, не активы UpgraderNFT. Остальные превью — символы-заглушки. Рендерер `vendor/lottie.min.js` — `lottie-web` 5.13.0 под лицензией MIT; текст лицензии находится в `vendor/lottie.LICENSE.md`.

Для локальной проверки запусти из этой папки `python3 -m http.server 8765` и открой `http://127.0.0.1:8765/`. Через `file://` загрузка анимаций может не работать. Публикуется только содержимое этой папки, без токена бота и базы данных.
